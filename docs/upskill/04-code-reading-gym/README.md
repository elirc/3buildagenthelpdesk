# Code Reading Gym

Passive reading is not enough. This module makes you annotate, trace, compare, and review.

Use a notebook or comments in a temporary copy. Do not edit product code for these drills unless a ticket asks you to.

Routine:

1. Read the anchor.
2. Predict behavior.
3. Annotate inputs, outputs, dependencies, invariants, side effects, failure modes.
4. Compare to the self-grade rubric.
